# Tools

## `setup.ps1`
Installs the local Lua development environment.

## `rename-template.ps1`
Renames the template and replaces placeholders.

## `test.ps1`
Executes all unit tests.

## `build.ps1`
Runs tests, generates metadata and installs the mod locally.

## `generate-metadata.ps1`
Generates _mod.info_, _README.md_ and _workshop.txt_.
