description=Afterwards, [b]./tools/test.ps1[/b] will execute the tests (there are two in this project).
description=
description=[b]./tools/build.ps1[/b] will execute the tests and if that was successful, copy the mod Data into the [b]Project Zomboid[/b]  repository.
description=
description=[b]./tools/generate-metadata.ps1[/b] will generate the meta data ([i]mod.info[/i], [i]README.md[/i], [i]workshop.txt[/i]) from a common source. This source is
description=

description=[*] [i]metadata.json[/i] - for general info like ID and version
description=[*] [i]description.md[/i] - for a long description of your mod
description=[*] [i]tools/templates/README.md[/i] - a template for the README file of this repository; add stuff that is only relevant for the code here
description=[/list]
